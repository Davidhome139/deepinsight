# 提示词工程自我迭代功能 - 产品需求文档

## 概述

* **摘要**：为提示词工程服务添加自我评估与优化功能，实现模型输出的自动迭代改进，提高输出质量。

* **目的**：解决模型输出质量不稳定的问题，通过自我评估和迭代优化，持续提高模型的输出质量和准确性。

* **目标用户**：使用提示词工程功能的开发者和最终用户。

## 目标

* 实现模型自我评估机制，评估输出质量

* 基于评估结果生成改进建议

* 实现输出的迭代优化，支持多轮迭代

* 在提示词工程服务中集成自我评估和优化功能

## 非目标（范围外）

* 不修改现有的提示词工程核心功能

* 不影响其他服务的正常运行

* 不添加新的依赖库

## 背景与上下文

* 提示词工程服务已经实现了角色专业化、输出结构化、思维链增强等功能

* 配置中已经包含了 `SelfEvaluation` 字段，但尚未实现相关功能

* 自我迭代功能是提示词工程的重要组成部分，能够显著提高模型输出质量

## 功能需求

* **FR-1**：实现 `SelfEvaluate` 方法，让模型评估自己的输出质量

* **FR-2**：实现 `OptimizeOutput` 方法，基于评估结果迭代优化输出

* **FR-3**：在 `ProcessMessage` 方法中集成自我评估和优化功能

## 非功能需求

* **NFR-1**：自我评估和优化过程不应显著增加响应时间

* **NFR-2**：迭代优化应在合理的轮数内完成

* **NFR-3**：应保持与现有提示词工程功能的兼容性

## 约束

* **技术**：使用现有的 AI 服务接口，不添加新的依赖

* **业务**：保持与现有提示词工程配置的一致性

* **依赖**：依赖现有的 `ai.AIService` 接口

## 假设

* 模型能够对自己的输出进行有效的评估

* 评估结果能够指导输出的优化

* 迭代优化能够在合理的时间内完成

## 验收标准

### AC-1：自我评估功能

* **给定**：提示词工程服务已启用，且 `SelfEvaluation` 为 true

* **当**：模型生成输出后

* **然后**：模型应评估自己的输出质量，并生成改进建议

* **验证**：`programmatic`

* **说明**：自我评估结果应包含质量评分和具体的改进建议

### AC-2：迭代优化功能

* **给定**：自我评估功能已实现，且评估结果显示需要改进

* **当**：启用迭代优化功能

* **然后**：模型应基于评估结果优化输出，支持多轮迭代

* **验证**：`programmatic`

* **说明**：优化后的输出质量应明显高于原始输出

### AC-3：集成到 ProcessMessage 方法

* **给定**：提示词工程服务已启用，且 `SelfEvaluation` 为 true

* **当**：调用 `ProcessMessage` 方法处理消息

* **然后**：方法应自动触发自我评估和优化功能

* **验证**：`programmatic`

* **说明**：集成应无缝，不影响现有功能

### AC-4：与现有功能兼容性

* **给定**：提示词工程服务已启用，且配置了其他功能（如角色专业化、输出结构化等）

* **当**：同时启用自我评估功能

* **然后**：所有功能应正常工作，不相互冲突

* **验证**：`programmatic`

* **说明**：自我评估功能应与现有功能协同工作
